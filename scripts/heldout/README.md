## Keying decisions

- 'Fair' prep is adequate (per brief). Good-left/poor-right prep is keyed inadequate (a poorly prepared segment, analogous to a Boston segment < 2).
- Aronchick/Ottawa are only used with a verbal grade; keyed by that grade.
- Prior histology quoted in the indication (previous tubular adenomas) is not a result for this procedure: histology = no.
- An 'Intended extent: caecum' field is a plan, not documentation: caecum = no when the actual extent says otherwise. A CTC recommendation naming the caecum does not document it.
- Boston scores and right-colon prep comments only appear when the caecum is documented as reached (a right-segment score would otherwise imply right-colon inspection).
- Withdrawal time alone is never used as evidence of caecal intubation; silent-extent reports never mention the ascending colon, caecum, landmarks or TI.
- Polyps left in situ (diminutive, hyperplastic-appearing, rectosigmoid) are tissue = no.
- Arabic-only key statements (caecum reached/not reached, prep grade) are keyed as a bilingual clinician would read them.
